# Feature matrix

## Working locally / offline
- Recipe library and manual/paste import
- Physical profile and editable calorie/macro targets
- Weight-loss, maintenance and gain goal calculations
- Dietary restrictions, allergies, likes/dislikes and cuisine preferences
- Automatic target-driven weekly meal generation
- Pantry-aware grocery aggregation
- Grocery check-off and weekly budget
- PWA/offline cache

## Free optional enhancements
- Supabase cross-device backup/sync
- Cloudflare Worker recipe JSON-LD importer
- Browser/local AI prompt workflows

## Deliberate boundaries
RecipeFlow does not copy proprietary ReciMe or Eat This Much code, databases, branding or paid partner integrations. Retailer checkout/live universal pricing and protected social-media extraction are not represented as guaranteed free features.
